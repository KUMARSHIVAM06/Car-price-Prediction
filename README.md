This project predicts the selling price of a car using Machine Learning techniques. By analyzing factors such as car brand, model, manufacturing year, fuel type, transmission, mileage, engine size, and ownership history, the model estimates a fair market price for a vehicle.

The goal of this project is to help buyers, sellers, and dealerships make data-driven pricing decisions.

⸻

🎯 Objectives

* Predict car prices accurately using historical data.
* Perform data cleaning and preprocessing.
* Explore relationships between vehicle features and price.
* Train and evaluate machine learning models.
* Build a simple prediction system for new car data.
